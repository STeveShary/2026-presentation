## Abstract

The Krebs Cycle turns glucose into ATP. CI/CD turns code into deployments. Both are energy-intensive, feedback-driven, and fail without oxygen (or tests). Let’s compare cellular respiration to DevOps pipelines!

The tools we need to create better CI/CD pipelines are already within us - literally! By breaking down the building blocks to metabolism in the body, I want to show Engineers that biological science and computer science are inherently interconnected. If we can break down pipelines in the same way, we can see how to automate in the same efficient way that all of our bodies already do.
