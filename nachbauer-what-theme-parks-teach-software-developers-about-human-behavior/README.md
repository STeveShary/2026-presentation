## Abstract

Theme parks solved user experience long before apps existed.

They mastered onboarding before SaaS, wayfinding before mobile UX, gamification before Silicon Valley, and emotional retention before analytics dashboards became standard.

Every queue, sign, sound, transition, and interaction inside a theme park is intentionally designed to shape human behavior. The same principles apply to software, whether developers realize it or not.

In this interactive session, attendees will reverse engineer the hidden behavioral systems behind theme parks, live events, immersive environments, and civic experiences — then apply those same principles to software, accessibility, onboarding, retention, and product design.

Using real world examples from a rapidly deployed accessibility system built for a 200,000+ attendee public event, we will break down:
• Why onboarding is really arrival choreography
• Why accessibility is emotional infrastructure, not just compliance
• How friction impacts trust, participation, and retention
• Why users abandon products when the “storyworld” breaks
• How feedback loops shape behavior in physical and digital spaces
• What live events teach us about designing systems under pressure

Attendees will participate in live behavioral analysis, rapid creative problem solving prompts, and collaborative system mapping exercises designed to shift how they think about user experience and human centered technology.

Drawing from themed entertainment design, IAAPA industry principles, accessibility infrastructure, and rapid prototyping workflows, this session explores how constraints can become catalysts for innovation.

This is not a talk about roller coasters. It is a talk about designing systems for real human behavior instead of ideal user behavior.

Attendees will leave with practical frameworks, new mental models, and immediately applicable strategies for building software experiences that people trust, remember, and return to.
